# roadmap-me

A lightweight React mind-map builder for creating roadmap-style visual maps. Add nodes, child nodes, mark tasks done, edit titles, write Markdown/HTML, attach image links, and save/load maps as JSON. Runs fully in the browser with a fast, modern REST-powered workflow.
